# Trebired .github

The organization profile GitHub shows on the Trebired organization page.

This repository owns the wording of the profile and its links. GitHub owns where and how the profile is rendered. It does not own the organization's policies or brand, which live in `Trebired/meta`, or any repository's own documentation.

## Documents

| File | Covers |
| --- | --- |
| `profile/README.md` | The organization profile: how to contribute, the repositories to explore, what a pull request needs, how the organization works, and where to report a vulnerability |

## Structure

`profile/README.md` is the one path GitHub reads for an organization profile, so this repository keeps that path instead of a `<document>/en.md` folder.

## Format

GitHub-flavoured Markdown as GitHub renders it on the organization page: headings, paragraphs, lists, tables, links, badges and `<picture>` with a dark-mode source. Scripts and styles are dropped. The logo is linked from `Trebired/meta`, never copied here.

## Language

English only. GitHub shows one profile to every reader.

## What It Does Not Do

This repository does not:

- Hold policies, a code of conduct, a security policy or a contributing guide. They are published on trebired.com from `Trebired/meta`.
- Copy the logo or the colours.
- Describe client work. That is the profile of the `Trebired-Clients` organization.
